# Эмулятор командной оболочки (вариант 22)

Графический (GUI) эмулятор командной строки UNIX-подобной ОС,
написанный на Python с использованием библиотеки `tkinter`.

## Этап 1. REPL

Минимальный прототип: окно с областью вывода и строкой ввода.
Команды вводятся в нижнюю строку и выполняются по нажатию Enter.

### Возможности

- **Графический интерфейс.** Окно на `tkinter`: сверху область вывода,
  снизу строка ввода команды.
- **Имя VFS в заголовке окна.** Заголовок: `Эмулятор оболочки — <имя VFS>`.
- **Парсер с поддержкой кавычек.** Аргумент в одинарных или двойных
  кавычках считается одним словом: `cd "My Folder"` → `['cd', 'My Folder']`.
  Незакрытая кавычка — ошибка разбора.
- **Команды-заглушки `ls` и `cd`.** Выводят своё имя и аргументы.
- **Команда `exit`.** Закрывает эмулятор (с аргументами — ошибка).
- **Обработка ошибок.** Неизвестная команда, незакрытая кавычка,
  лишние аргументы у `exit`.

### Команды

| Команда | Что делает |
|---|---|
| `ls [аргументы]` | заглушка: выводит `ls: аргументы [...]` |
| `cd [аргументы]` | заглушка: выводит `cd: аргументы [...]` |
| `exit` | закрывает окно эмулятора |

## Этап 2. Конфигурация

Эмулятор настраивается параметрами командной строки. При запуске все
заданные параметры выводятся в окно и в консоль (отладочный вывод).

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | путь к физическому расположению VFS; имя файла попадает в заголовок окна |
| `--script ПУТЬ` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной в строке. Команды
выполняются по очереди, на экране показываются и ввод, и вывод — как будто
их набирает пользователь.

- Комментарии начинаются с `#` (синтаксис Python): вся строка или конец
  строки. Символ `#` внутри кавычек комментарием не считается.
- Пустые строки пропускаются.
- Ошибочная команда выводит сообщение об ошибке, скрипт продолжается.
- Если файл скрипта не найден, в окне выводится сообщение об ошибке.

Пример: `examples/startup_stage2.txt`.

### Скрипты для запуска с разными параметрами

| Скрипт | Что проверяет |
|---|---|
| `scripts/run_default.sh` | запуск без параметров |
| `scripts/run_with_vfs.sh` | параметр `--vfs` |
| `scripts/run_with_script.sh` | параметр `--script` |
| `scripts/run_all_params.sh` | оба параметра вместе |
| `scripts/run_missing_script.sh` | ошибка: скрипт не найден |

### Пример отладочного вывода

```
[DEBUG] Параметры запуска:
[DEBUG]   --vfs    = /home/user/my_vfs
[DEBUG]   --script = examples/startup_stage2.txt
[DEBUG] Выполнение скрипта examples/startup_stage2.txt
my_vfs:~$ ls
ls: аргументы []
...
[DEBUG] Скрипт выполнен
```

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/main.py` | точка входа |
| `src/gui.py` | окно эмулятора (`EmulatorWindow`) |
| `src/shell.py` | логика оболочки (`Shell`, `CommandResult`) |
| `src/shell_parser.py` | разбор строки команды (`parse_command`) |
| `src/config.py` | параметры командной строки (`parse_args`, `Config`) |
| `src/script.py` | загрузка стартового скрипта (`load_script`) |
| `examples/` | стартовые скрипты эмулятора |
| `scripts/` | скрипты ОС для запуска с разными параметрами |
| `tests/` | модульные тесты (`unittest`) |
| `run.sh` | скрипт запуска |

## Функции и классы

- `parse_command(line)` — разбивает строку на слова с учётом кавычек,
  при незакрытой кавычке бросает `ParseError`.
- `Shell.execute(line)` — разбирает строку, находит команду и выполняет её,
  возвращает `CommandResult(output, should_exit)`.
- `Shell.prompt()` — строка приглашения, например `vfs:~$ `.
- `EmulatorWindow.run_line(line)` — выводит команду в окно, выполняет её
  и печатает результат.
- `parse_args(argv)` — читает параметры `--vfs` и `--script`,
  возвращает `Config`.
- `format_config(config)` — строки отладочного вывода параметров.
- `load_script(path)` — читает стартовый скрипт, убирает комментарии и
  пустые строки; при ошибке чтения бросает `ScriptError`.
- `EmulatorWindow.run_script(path)` — выполняет команды скрипта по очереди.

## Требования

- Python 3.8+
- tkinter (в Fedora: `sudo dnf install python3-tkinter`,
  в Ubuntu: `sudo apt install python3-tk`)

## Запуск

```
./run.sh
./run.sh --vfs vfs/my_vfs --script examples/startup_stage2.txt
```

или

```
python3 src/main.py --vfs ПУТЬ --script ПУТЬ
```

## Тесты

```
python3 -m unittest discover -s tests
```
